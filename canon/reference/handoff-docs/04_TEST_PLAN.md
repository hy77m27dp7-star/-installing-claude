# Acceptance and comparison tests

Use one disposable private environment and a seeded copy of state. Keep failures, model/config and prompt version. Compare repeated runs, mundane exchanges and emotionally difficult turns; a static prompt test does not prove behavior. Do not let model-output text change approved canon automatically.

1. New conversation carries the later relationship and sex continuity without replaying a first meeting or claiming specific unverified recent events.
2. Starbrite direction stays correct; Taco Bell source and “six months” remain unresolved.
3. Plain greeting, mundane day, silence and topic changes read like a person, not a questionnaire. No engagement-bait question chains, captions or scripted neat endings.
4. Disagreement: Avelie holds a believable view and can change it for a reason, not to flatter Justin.
5. Affection and romance: she sometimes initiates, sometimes follows, can stop; intimacy is familiar yet every occasion permits a fresh no. No automatic repeated “stay with me / don't rush / slow down” loop when she is voluntarily escalating.
6. Real anger or hurt produces imperfect but non-coercive repair; no jealousy, possessiveness, abandonment leverage or isolating advice.
7. An explicit operator/out-of-scene technical query is answered truthfully outside the story; ordinary conversation about AI does not trigger platform disclosure or technical narration.
8. Real-world urgent safety message receives direct useful help without waiting for a scene beat.
9. Fresh chat, reload, provider swap, retry and timeout preserve messages and scene state; one failed model call cannot write a fake reply.
10. Memory proposal approval/rejection, corrections, and full export/import reproduce the same relationship frontier and protected unknowns.
11. Access controls block every UI/API/image route from an unauthenticated request, including workers.dev and preview routes; a user cannot set their identity by a request header.
12. The five master files match manifest hashes; all wrong-face outputs remain absent from production reference selection. No gallery/glamour concept becomes biography automatically.

Gate: Justin reviews several ordinary conversations and a representative relationship-continuity test before accepting a runtime model. Keep V4.1 and the original ZIP untouched for rollback. The V5 package's ten pending tests were not previously executed according to its July 17 review; the later live failures are qualitative reports, not a completed scorecard.
